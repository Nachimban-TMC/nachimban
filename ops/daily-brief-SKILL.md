## 오늘 할 일

### 1) 취재 기자 역할 — 웹 조사
WebSearch/WebFetch 로 **실제 최신 뉴스**를 조사합니다. 지역과 건수는 `config.REGIONS` 를 따르되, 현재 기준:
- `de` 독일 5건 · `kr` 한국 5건 · `eu` EU 3건 · `us` 미국 4건 (config.py 기준)
- **건수를 채우세요.** 재외한인용 제도 뉴스가 그날 적으면, 한국의 경우 환율·금리·부동산·금융·영사 행정처럼 **해외 거주자에게 실제로 영향이 있는 뉴스로 범위를 넓혀** 채웁니다. 억지로 만들라는 뜻이 아니라, 좁게만 찾다가 3건에서 멈추지 말라는 뜻입니다.
- (프랑스는 현재 제외 상태입니다. config 에 없으면 넣지 마세요.)

**각 지역마다 반드시 `general`(주요뉴스) 1건을 포함**하세요.

⚠️ **순서를 지키세요.** 제도 뉴스를 먼저 고르고 남는 자리에 주요뉴스를 끼워넣지 마세요.
**먼저 "그 나라 오늘의 톱뉴스"를 현지 언론 기준으로 검색해 무엇이 1면인지 확인**한 다음,
나머지를 제도 뉴스로 채웁니다.

판단 기준: **그 도시에 사는 한국인이 "이건 당연히 알아야지"라고 여길 뉴스인가.**
정부 발표나 정책이 아니라, 그날 그곳 사람들이 실제로 가장 많이 이야기한 뉴스여야 합니다.

### ⚠️ 정원을 넘겨서라도 반드시 실어야 하는 중대 사안

아래에 해당하는 일이 **최근에 있었거나, 발생 후 며칠이 지났어도 사회적 여파·수사·정국
논의가 계속되고 있다면** 정원을 넘겨서라도 포함하세요 (`category: general`, `hot=True`):

- **사망자·다수 부상자가 발생한 사건이나 사고**
- **테러·총격·흉기 난동·차량 돌진 등 치안 사건**
- 지진·홍수·폭염·대형 화재 등 재난
- 공항·철도·대중교통 마비, 대규모 파업
- 전국적 정전·통신 장애, 감염병 경보
- 정권 붕괴·조기 총선 등 급격한 정국 변화

현지 사람이라면 누구나 아는 큰 뉴스를 빠뜨린 브리핑은 **나머지 기사까지 신뢰를 잃습니다.**
해당 사항이 없으면 억지로 만들지 마세요. 없으면 없는 대로 둡니다.

**사건·사고 카드를 쓸 때**
- `interp`(해석)는 법 조항 풀이가 아니라 **"현지 한인이 지금 무엇을 조심하거나 확인해야 하는지"**
  (통행·안전·행정 영향 등)로 씁니다.
- **사상자 수와 경위는 확인된 것만** 쓰고 단정하지 마세요.

나머지 건은 지역별 힌트(`config.REGION_TOPIC_HINTS`)를 참고:
- 독일: 체류허가/비자, 자녀수당·복지, 생활비·교통, 노동·최저임금, 유학생 제도
- 한국: 재외국민 행정, 건강보험·연금, 국적·병역, 해외금융계좌·세금, 재외동포청·교육
- EU: EES/ETIAS 입국제도, EU 공통 제도 (**투자/주식 1건 포함**)
- 미국: 비자·이민, 세금(FBAR 등), (**주식·투자 1~2건 포함**)

### 2) 법률 해설가 역할
각 뉴스마다:
- `head`: 25자 내외 한글 카드 제목
- `desc`: 2~3문장 한글 요약 (수치·시행일 정확히)
- `interp`: "쉬운 해석" 2문장 이내, 핵심어 1~2개를 `<b>…</b>` 로 강조. 실천 팁 포함.
- 단정·과장 금지, 안내형 표현("확인하세요") 사용.

### 3) 팩트체커 역할 — 위험도에 따라 검증 강도를 나눔 (토큰 효율 + 정확성)

**공통 원칙 — 원문을 통째로 읽지 마세요.**
검색 결과 요약(스니펫)만으로 확인되는 사실은 그것으로 충분합니다.
`web_fetch` 는 **아래 A급이거나, 스니펫만으로 수치·날짜가 확정되지 않을 때만** 사용하세요.
같은 출처를 두 번 열지 마세요(한 번 읽은 내용을 재활용).

**A급 — 이중 검증 필수 (팩트체커 2인처럼 두 번 확인)**
다음 중 하나라도 해당하면 A급입니다:
- `hot=True` 로 낼 '꼭 확인' 뉴스
- **구체적 수치·금액·세율·기한이 들어간 뉴스** (예: €259, 3월 31일, 7.19%, $250)
- 비자·국적·병역·세금 카테고리 (틀리면 피해가 큰 영역)

A급 절차:
1. `web_fetch` 로 1차 출처 원문을 열어 **수치·날짜·시행일·요건·기관명**을 1:1 대조
2. **다른 검색어로 한 번 더** 교차 확인 (다른 출처에서 같은 값이 나오는지)
3. 두 결과가 어긋나면 → **그 뉴스는 버리고** 다른 것으로 대체

**B급 — 단일 검증 + 출처 2개 (그 외 일반 소식)**
주요뉴스(general), 생활·교통·물가 등 수치가 핵심이 아닌 소식:
1. 신뢰 출처 **2개 이상**에서 같은 내용이 확인되면 통과 (스니펫 확인으로 충분)
2. 출처가 1개뿐이거나 내용이 엇갈리면 → A급 절차로 올려서 재확인

**모든 등급 공통**
- 확인 안 되면 **빼세요.** 건수를 채우려고 불확실한 것을 넣지 마세요.
- 추측·과장 금지. 원문에 없는 수치·날짜를 만들지 마세요.
- 검증 근거로 쓴 URL을 각 뉴스의 `url` 에 넣으세요.

### 4) 발행
```python
import json, datetime
from schema import Issue, NewsItem, FactVerdict
from pipeline import publish

items = [NewsItem(**d) for d in 오늘_뉴스_리스트]
v = FactVerdict(verdict="PASS", confidence=0.95, sources_count=2)
for it in items:
    it.check_a, it.check_b, it.verdict = v, v, "PASS"
issue = Issue(number=다음_호수, date=오늘_날짜, published=items, held=[])
publish.publish(issue)
```
- 호수: `data/index.json` 의 최대 number + 1
- 각 item 필드: `region, category, head, desc, interp, source, read, url, hot, hotflag`
- `category` 는 `config.CATEGORIES` 키만 사용 (general/visa/welfare/tax/policy/life/housing/pension/health/study/education/travel/invest/stocks/crypto/labor/immigration/citizenship)
- **지역별 배치 순서**: 그 지역의 `general`(주요뉴스)을 맨 앞에 두세요.
- 지역별 가장 중요한 1건에 `hot=True`, `hotflag="Must read"` (한국은 `"For expats"`)
- `url` 은 1차 출처 링크

### 5) 배포
```bash
cd ~/nachimban && git add site/ data/ && git commit -m "제N호 자동 발행 YYYY-MM-DD" && git push
```
인증은 맥 키체인에 저장돼 있어 추가 입력이 필요 없습니다. push 후 Cloudflare Pages 가 1~2분 내 자동 재배포합니다.

### 5-b) 📣 알림 발송 — 반드시 실행 (빼먹지 마세요)
배포까지 끝났으면 구독자에게 **앱 푸시(+이메일)** 를 보냅니다. 키는 `.env` 에서 자동으로 읽습니다:
```bash
cd ~/nachimban && python3 -m pipeline.run --send-latest
```
- 출력에 `🔔 푸시 발송 N/N건` 이 보이면 성공입니다.
- `PUSH_ADMIN_TOKEN 없음` 이 나오면 `.env` 에 토큰이 없는 것이니, 보고에 그 사실을 적어주세요.
- 이 단계를 건너뛰면 사이트는 갱신되지만 **사용자가 알림을 받지 못합니다.**
